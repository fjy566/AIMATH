# 编辑器与答题模板升级方案

## 目标

把答题区和学习工作台里的笔记编辑体验统一成一套可预期的学习工具：文字、公式、分点和图片都能快速输入，输入结果能立即确认；每个细分题型的模板都要能够直接转化为答题纸上的得分步骤。

## 交互设计

- 答题输入使用文字与公式混合编辑器。公式工具仍按分类折叠，文字工具提供加粗、斜体、链接、引用、分点、小题、撤销和重做。
- 文本输入支持 Ctrl/Cmd+B、I、U、K；Enter 会延续当前有序或无序列表，空列表再次回车退出列表；Tab 和 Shift+Tab 用于缩进与反缩进。
- 输入框显示字符统计和简短快捷键提示。选择题保留按钮式作答，填空题和解答题保持实时 KaTeX 预览。
- 图文笔记采用编辑区与预览区并排布局，小屏幕自动上下排列。Markdown 模式提供快捷插入、实时预览、列表续写和字符统计。
- 富文本与 Markdown 互转时保留标题、粗体、斜体、下划线、引用、列表、链接、图片和公式文本。预览只允许安全链接与图片地址，移除脚本、事件属性和不受信任的标签。

## 模板数据

每个数学二知识块的 65 个细分题型继续使用已有的具体题型目录、公式卡片、解题框架和易错点。后端根据这些内容生成四段可套写结构：

1. 题型定位：写明题目目标和主方法。
2. 条件核验：写出定理或公式的使用前提。
3. 核心过程：按该题型已有的具体框架逐步展开。
4. 结论复核：回到题目要求，并提醒该题型的高频失分点。

结构通过现有工作台 API 返回，前端以步骤卡展示，并继续显示完整例题、来源答案和一次一题的变式练习。

## 兼容与验证

- 不新增前端依赖，沿用现有 KaTeX、CSS 令牌和本地优先数据接口。
- 断点下编辑器保持可用：桌面并排预览，移动端单列堆叠，输入字号避免移动浏览器自动缩放。
- 通过 JavaScript 语法检查、Python 全量核心测试、真实题库数量与工作台 API 检查，并保留 65 个题型模板的结构断言。
