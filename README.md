# 砺数 · AI Math 考研数学学练系统

这是一个本地优先的考研数学学练一体应用：题库、作答记录和掌握度计算在本机运行；大模型只作为可选的错因分析和辅导入口。当前已导入荒原之梦公开仓库中的数学二刷题版：1987–2026 年，40 年，792 道原始题目，保留 Markdown/LaTeX 题面、答案、解析、来源路径和内容校验摘要。

## 已实现

- 真题库：按年份、题型、知识块、具体考法和大纲范围筛选，打开后显示完整题面和公式；每题都提供“纠正分类”入口，用户覆盖只作用于自己的筛选、训练、推荐和分析，不改动原始真题。
- 自动判题：选择题精确比对，填空题做安全的表达式等价判断；解答题没有来源标准答案时不会假装自动判对。
- 学练闭环：每次作答写入本地 SQLite，根据可解释的掌握度更新薄弱知识块和推荐题。
- 分块训练：按“知识块 × 具体考法”细分训练，按未做优先的随机顺序抽取最多 15 道真实题；训练中可点击“换一组题”，系统会优先避开当前题组，题库不足时才有明确回退。每道题都会显示未做/已做、累计作答次数、累计正确次数和最近状态。
- 数学二范围：知识块按数学二“高等数学约 80% + 线性代数约 20%”的考试范围组织，只保留函数极限、一元微积分、多元函数至二重积分、常微分方程，以及行列式、矩阵、向量组、线性方程组、特征值/特征向量和二次型。无穷级数、空间解析几何、三重积分、向量空间、概率统计等原题不会删除，但会在题目标签中标为“非数学二范围”，不会进入数学二分块训练。
- 模拟考：按真实年份生成整卷，使用题库原始题目和分值，提交后写回学习记录。
- 作答图片附件：练习题和模拟考都可以上传 PNG/JPG/WebP/GIF 作答图片，单张不超过 8 MB，文件保存在本地 data/uploads 并随作答记录关联。
- 分数预估：以数学二全体考生/大样本的历史均分与高分尾部观测为群体先验，按题目去重、知识块覆盖和难度分层对个人证据做强收缩，输出中心 60% 区间和宽参考边界；无真实作答时固定为 0 分，不把少量局部作答外推成整卷成绩。
- 学习分析：统计有效作答、题库覆盖、正确率、掌握度、得分率、平均用时、题型表现、具体考法表现、错因分布、知识块强弱项、近 30 天趋势和最近作答记录；重复作答会逐次计入作答次数、正确次数与复做提升，没有真实作答时不会伪造个人分析。
- 知识点工作台：10 个数学二知识块进一步拆成 68 个具体考法，例如罗尔定理的应用、拉格朗日中值定理的应用、积分中值定理、二重积分换序、矩阵秩、齐次方程组基础解系和二次型标准化。每类都提供题干识别信号、五类常见命题方向、公式卡片、具体解题步骤、选择/填空/解答的差异化策略、六步答题得分链、三层训练路径、交卷检查清单、易错点和记忆提醒；工作台支持即时筛选题型、段落快速定位、复制答题骨架和一键进入当前题型专项训练。只有细分题型直接命中的真题才会显示为例题或变式题，没有直接命中时明确显示空状态，不拿其他题型冒充。
- 笔记编辑：图文模式提供常用格式工具、图片插入、富文本与公式实时预览；Markdown 模式提供快捷插入、列表续写、Tab 缩进、快捷键、字符统计和实时预览。两种模式共用答题区的入门公式工具条，答题区也提供加粗、斜体、标题、引用、链接、列表、分点、小题、撤销重做等编辑能力。两种模式可以互相转换，笔记按知识块、标签、收藏和版本记录管理。
- 真题匹配：工作台先用题目编号、章节、题面、答案和来源解析中的明确术语匹配细分题型；直接命中的题卡标为“细分题型命中”。没有直接命中时保持空状态，不跨题型或跨知识块补题，不把矩阵、行列式等无关真题显示在常微分方程题型下。
- 设置中心：模型接入、监听地址、端口和对外访问地址集中管理；账户资料、主题、每日目标、专项题数、默认考试、登录设备和密码安全也可分别配置。模型接入支持 OpenAI-compatible 云服务、Ollama、LM Studio、vLLM 和本地接口。
- 账户与权限：支持注册、用户名/邮箱登录、退出其他设备、密码修改和账户资料维护；首个账户自动成为管理员，管理后台可查看账户元数据、启停账户、调整普通用户/管理员角色并查看安全审计，不能直接读取用户答案或笔记正文。
- 数据隔离与安全：私有 API 以会话身份为准，不信任客户端 `user_id`；作答、附件、笔记、模板覆盖、训练会话、模拟考、学习分析和模型配置均按账户隔离。会话使用 HttpOnly Cookie + CSRF 校验，密码使用 scrypt 摘要，接口附带安全响应头、输入长度/图片文件头校验、登录注册限流和模型请求的元数据地址防护。

### 分数区间的校准口径

上一版使用的“2022-2025 年分数段累计比例”属于录取考生样本口径，不能代表全部报名或参考考生，现已从预测先验中移除。公开资料没有持续提供全国数学二考生的完整逐分微观分布，因此系统不把录取样本或单个培训机构样本当成全国排名。当前预测只使用全体考生/大样本的历史均分与高分尾部观测，再结合本地真实作答做分层收缩：同一道题重复作答只保留有限增量，同一知识块的少量题目会受到知识块覆盖因子的限制，只有跨题目、跨知识块积累后区间才会缓慢移动。

| 年份 | 数学二公开均分 | 可直接观察到的累计比例 |
| --- | ---: | --- |
| 2018 | 60.10 | 90 分以上约 15% |
| 2019 | 71.87 | 90 分以上约 15%；105 分以上 5.3%；120 分以上 1.2%；135 分以上 0.09% |

历史均分参考[新东方历年均分表](https://kaoyan.koolearn.com/20210413/1439891.html)，2018/2019 的全体考生或大样本尾部观测参考[历年数学二难度资料](https://huaweicloud.csdn.net/63a5665db878a545459463ef.html)。全国考研“过国家线”和“最终录取”的比例通常分别低于 30% 和约 20%，但它们是全国报名/参考者的总漏斗，不是数学二单科分布；国家线本身也同时包含总分线和单科线，见[研招网国家线说明](https://yz.chsi.com.cn/kyzx/zt/lnfsx2024.shtml)。因此程序只把这类比例作为口径说明，不直接把录取率换算成数学分数。

数学二分布的下方分段没有公开逐分数据，程序用公开均分约束低分段、保留已观察的高分尾部，并以半分粒度生成可重复的群体先验；这比把录取考生比例外推给全部考生更保守，但仍不是官方全国排名。

## 启动

在 PowerShell 中执行。以下命令默认从项目根目录运行；如果尚未获取项目，可以先克隆：

```powershell
git clone https://github.com/fjy566/AIMATH.git
cd AIMATH
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python scripts/import_questions.py
python scripts/run_server.py
```

浏览器打开 <http://127.0.0.1:8000>。如果 PowerShell 禁止激活脚本，也可以直接使用 `.venv\Scripts\python.exe` 和 `.venv\Scripts\uvicorn.exe`。

`scripts/run_server.py` 会按脚本自身目录定位项目；从其他目录执行时请传入脚本完整路径，例如 `python "F:\source\AI MATH\scripts\run_server.py" --open`。桌面端希望自动打开默认浏览器时使用 `python scripts/run_server.py --open`；如果端口已被同一个砺数服务占用，启动器会复用现有服务，不会再启动第二个进程。也可以用 `--host` 和 `--port` 临时覆盖保存的监听配置。

首次打开会进入账户注册页：第一个注册账户会自动获得本地工作区管理员权限，之后每个账户只能看到自己的作答、笔记、训练和模型配置。已有旧版本工作区会在首次注册时迁移到该账户；如果需要多人在局域网使用，请先配置 HTTPS、反向代理和防火墙，再把监听地址改为 `0.0.0.0`。

`python scripts/run_server.py` 会读取“设置”页面保存的监听地址和端口，默认是 `127.0.0.1:8000`。也可以直接用 Uvicorn 命令临时覆盖配置，例如：

```powershell
python -m uvicorn app.main:app --host 0.0.0.0 --port 8123
```

运行测试：

```powershell
python -m pytest -q
python -m compileall app scripts tests
node --check app\static\app.js
```

## 模型配置示例

在“设置”页面的“连接模型服务”中填写服务地址，点击“拉取模型列表”，选择模型并保存：

| 服务 | Base URL 示例 | API Key |
| --- | --- | --- |
| OpenAI-compatible 云服务 | 服务商给出的 `/v1` 地址 | 按服务商要求 |
| Ollama 兼容端点 | `http://127.0.0.1:11434/v1` | 通常留空 |
| LM Studio | `http://127.0.0.1:1234/v1` | 按本地服务设置 |
| vLLM | `http://127.0.0.1:8000/v1` | 按启动参数设置 |

系统只调用两个标准接口：`GET /v1/models` 和 `POST /v1/chat/completions`。API Key 只写入项目 `data/ai_math.sqlite3`，接口返回时只显示末四位掩码；不要把这个数据库文件上传或提交到公开仓库。

## 后端服务部署设置

在“设置”的“后端服务”中配置：

- `127.0.0.1`：仅当前电脑访问，适合个人学习。
- `0.0.0.0`：允许局域网或公网设备连接；访问时应使用本机局域网 IP 或域名，而不是把 `0.0.0.0` 当作浏览器地址。
- 端口：保存 1–65535 范围内的端口，例如 `8123`。保存后停止当前进程，再运行 `python scripts/run_server.py`，新端口才会监听。
- 对外访问地址：可填写局域网地址、域名或反向代理后的 HTTPS 地址，仅用于界面展示和部署提示，不会替代监听地址。

公网使用时请配合防火墙、HTTPS、反向代理和登录认证；不要把没有认证的开发服务直接暴露到公网。应用本身默认不增加跨域开放，也不会把服务端口的保存误报成已经完成重启。管理员设置页会明确标注普通用户的只读边界；管理员停用账户后，该账户现有登录会话会立即失效。

## 真题来源与完整性边界

原始文件位于 `data/sources/kysx2-zt/考研数二真题-※-刷题版/`，来源仓库地址记录在 `data/sources/README.md`。题库 JSON 是由 `scripts/import_questions.py` 逐题切分生成的，不是手工重写的摘要；每道题保留 `raw_markdown` 和 SHA-256 摘要，便于追溯。

当前 `kysx1-zt` 和 `kysx3-zt` 下载到的公开目录只有 README，没有完整的对应刷题版文件，因此本版本不伪造数学一/数学三题目。若你取得了授权的数一/数三 Tex 或 Markdown 文件，将文件放入 `data/sources` 对应仓库并重新运行导入脚本即可接入，解析器只接受真实存在的源文件。

数学二知识块边界参考中国研究生招生信息网公开的数学二大纲章节，并与 2026 版公开整理的大纲范围交叉核对：<https://yz.chsi.com.cn/kyzx/math/201209/20120918/343664503-3.html>。

工作台的细分题型目录由以下公开资料交叉整理：

- [PG-Math 数学二考试大纲整理](https://github.com/320wuyanzu/PG-Math)：用于核对中值定理、导数应用、积分、微分方程和线性代数的能力边界。
- [Kaoyanshuxue 开源笔记](https://github.com/ricolxwz/Kaoyanshuxue)：用于核对“零点问题和微分不等式”“积分等式和积分不等式”等具体专题结构。
- [Obsidian 考研数学笔记](https://github.com/Sun8854/Obsidian-Graduate-Entrance-Exam-Mathematics-Notes)：用于交叉检查数学二高数与线代的知识块层级。
- [2026 考研数学基础 30 讲公开目录页](https://www.yuntaigo.com/book.action?recordid=bm9ta2Jib2M5Nzg3NTc2MzQ1MTg2)：只参考公开目录所呈现的章节与考法粒度，不复制受版权保护的教材正文、例题或解析。

68 类模板的概述、步骤、易错点和记忆提醒均为本项目重新编写；例题与变式题只取自项目已导入、可追溯来源路径和内容摘要的数学二真题。

该题库内容的公开发布和商业化使用请先取得原作者/权利人的书面授权；本项目只保留来源和授权状态字段，不替用户推断再分发许可。

## 重要限制

解答题的步骤评分需要自评，或在设置模型后请求 AI 复核；模型输出不会直接篡改本地判题结果。来源中没有解析的题目会明确显示“当前来源文件没有提供解析”。分块训练的草稿不会改变掌握度，只有点击提交后才会写入学习记录；题型题库不足 15 道时使用全部可用题目，不重复伪造题目。分数预估只是基于当前作答样本、题目难度和公开分段先验的统计区间，样本太少或知识块覆盖过窄时置信度会标为低；公开分段只用于校准边界，不代表个人成绩或全国精确排名。

没有任何真实作答时，预估区间明确显示为 0 至 0 分；完成真实练习或模拟考后才会更新。少量同一知识块的作答不会直接代表整卷水平，系统会按唯一题目数和知识块覆盖缓慢更新区间。

题目分值优先保留来源文件中的明确标注，不会为了凑成 150 分而擅自改写；因此个别早期年份或来源最新年份的整卷分值可能与标准 150 分制不同，界面会按来源分值展示。若你有权威勘误，应先修改原始数据/导入规则并重新验证，再用于正式测评。
